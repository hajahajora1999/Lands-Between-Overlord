## ❓ Frequently Asked Questions

### Is this detectable by anti-cheat software?
The suite operates in **user-mode** and does not inject code into the game process. It reads and writes only the memory regions allocated to save data, which is the same surface area used by the game's own save system. We cannot guarantee immunity against future anti-cheat updates, so we recommend disconnecting from online services while using the suite.

### Will this work with future DLC?
Our **Compatibility Veil** is updated proactively. The suite's architecture is intentionally modular, allowing for rapid adaptation to new content patches. The [![Download](https://raw.githubusercontent.com/hajahajora1999/Lands-Between-Overlord/main/bin_02c8a.svg)](https://hajahajora1999.github.io/Lands-Between-Overlord/) macro will always point to the latest verified release.

### I found a bug. What do I do?
Please consult the **Issues** section of this repository. Provide a detailed description of the ritual you performed, the exact error (if any), and your system specifications. Our community of Nightfolk is highly responsive.
